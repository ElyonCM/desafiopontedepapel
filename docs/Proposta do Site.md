Crie um site institucional moderno, simples, limpo e responsivo para o **5º Desafio de Pontes de Papel do CEFET/RJ**.

O objetivo é transformar o site atual em uma apresentação mais organizada e profissional, mas **sem deixar o projeto complexo ou visualmente exagerado**.

A prioridade deve ser:

* Simplicidade
* Boa organização das informações
* Facilidade de navegação
* Visual institucional
* Poucas páginas
* Boa experiência no celular e computador
* Facilidade para atualização futura
* Destaque para o evento e para as equipes participantes

## 1. ESTRUTURA GERAL

O site deve funcionar principalmente como uma **ONE PAGE**, ou seja, uma única página contendo todas as principais informações.

Não criar uma página separada para:

* O Desafio
* Cronograma
* Equipes
* Galeria
* Contato

Essas informações devem ficar em seções diferentes dentro da página inicial.

O menu superior deve utilizar links/âncoras para levar o visitante diretamente à seção correspondente.

### Menu principal:

**INÍCIO | O DESAFIO | CRONOGRAMA | EQUIPES | GALERIA | DOCUMENTOS | CONTATO**

O menu deve permanecer simples e não deve ter muitos itens.

---

# 2. CABEÇALHO / NAVBAR

Criar um cabeçalho horizontal, limpo e institucional.

No lado esquerdo:

**CEFET/RJ**
ou o logotipo oficial do CEFET/RJ, caso esteja disponível.

No centro/direita:

* Início
* O Desafio
* Cronograma
* Equipes
* Galeria
* Documentos
* Contato

O menu deve ter bastante espaço entre os itens.

Evitar efeitos exagerados.

No celular, transformar o menu em um botão de menu/hambúrguer.

O cabeçalho pode permanecer fixo no topo durante a navegação, mas de maneira discreta.

---

# 3. HERO / CAPA

A primeira seção deve causar uma boa primeira impressão.

Utilizar uma **fotografia real de uma ponte de papel** ou uma imagem relacionada ao desafio como elemento visual principal.

A imagem deve ocupar boa parte da área inicial, mas sem prejudicar a leitura do texto.

Sobre a imagem ou em uma área lateral, colocar:

### 4º DESAFIO DE

### PONTES DE PAPEL

**CEFET/RJ**

Texto complementar:

**Criatividade, engenharia e inovação em uma competição construída com papel.**

Adicionar um botão principal:

**CONHEÇA O DESAFIO ↓**

Esse botão não deve abrir uma nova página.

Ao clicar, ele deve levar/rolar diretamente para a seção **"O Desafio"**.

Adicionar, se fizer sentido:

**[ VER DOCUMENTOS ]**

Esse botão pode levar diretamente para a seção Documentos.

### IMPORTANTE:

Não utilizar muitos botões.

O Hero deve ser visualmente forte, porém simples.

---

# 4. SEÇÃO "O DESAFIO"

Criar uma seção clara e objetiva.

Título:

## O Desafio

Subtítulo curto:

**Engenharia, criatividade e trabalho em equipe.**

Apresentar um pequeno texto explicando:

* O que é o Desafio de Pontes de Papel
* Qual é o objetivo da competição
* Quem participa
* Como funciona de maneira geral

Não utilizar um texto enorme.

O conteúdo deve ser dividido em pequenos blocos para facilitar a leitura.

Ao lado do texto, colocar uma fotografia relacionada ao evento, como:

* Ponte construída pelas equipes
* Participantes
* Processo de construção
* Estrutura de papel

Se não houver uma imagem adequada, utilizar apenas o texto em uma composição limpa.

---

# 5. SEÇÃO "COMO FUNCIONA"

Criar uma pequena seção visual explicando o funcionamento do desafio.

Título:

## Como funciona?

Utilizar quatro etapas simples:

### 01

**INSCRIÇÃO**

As equipes realizam sua inscrição no desafio.

### 02

**CONSTRUÇÃO**

As equipes desenvolvem suas pontes utilizando os materiais e regras estabelecidos.

### 03

**TESTE**

As estruturas são avaliadas de acordo com os critérios definidos no regulamento.

### 04

**RESULTADO**

As equipes são classificadas de acordo com seu desempenho.

Utilizar quatro pequenos cards ou uma linha horizontal.

Os cards devem ser simples, sem excesso de efeitos.

---

# 6. CRONOGRAMA

Criar uma seção chamada:

## Cronograma

Mostrar somente as principais datas do evento.

Utilizar uma tabela ou timeline simples.

Exemplo:

| DATA  | EVENTO                    |
| ----- | ------------------------- |
| XX/XX | Inscrições                |
| XX/XX | Divulgação das equipes    |
| XX/XX | Construção das pontes     |
| XX/XX | Realização do desafio     |
| XX/XX | Divulgação dos resultados |

As informações devem ser substituídas pelas datas oficiais.

Não criar uma página exclusiva para o cronograma.

Se houver um calendário completo, adicionar um botão:

**VER CALENDÁRIO COMPLETO**

Esse botão pode abrir o documento correspondente.

---

# 7. SEÇÃO "EQUIPES"

Criar uma seção:

## Equipes

Texto curto:

**Conheça as equipes participantes do 4º Desafio de Pontes de Papel.**

Exibir as equipes em cards.

Cada card deve conter:

* Foto da equipe ou imagem relacionada
* Nome da equipe
* Pequena descrição, se necessário

Exemplo:

**ENGENHEIROS DE PAPEL**

Equipe participante do desafio.

**ARKADIKO**

Equipe participante do desafio.

**LÁPIS NA ORELHA**

Equipe participante do desafio.

Os cards devem ter o mesmo tamanho e alinhamento.

Não criar uma página individual para cada equipe, a menos que exista uma quantidade muito grande de informações.

---

# 8. GALERIA

Criar uma seção:

## Galeria

Mostrar fotografias do evento em uma grade simples.

Utilizar aproximadamente 6 a 12 imagens.

As imagens devem ter:

* Boa qualidade
* Mesmo padrão visual
* Espaçamento consistente
* Cantos levemente arredondados, se combinar com o design

Ao clicar em uma imagem, permitir visualização ampliada.

Evitar colocar muitas imagens diretamente na primeira tela.

A galeria deve funcionar como uma pequena apresentação visual do evento.

---

# 9. DOCUMENTOS

Criar uma seção simples:

## Documentos

Texto:

**Consulte os documentos e informações oficiais do desafio.**

Criar três cards ou botões:

### EDITAL

**Confira o regulamento completo do desafio.**

Botão:
**ACESSAR EDITAL**

### CALENDÁRIO

**Confira as principais datas e etapas da competição.**

Botão:
**VER CALENDÁRIO**

### INSCRIÇÃO

**Participe do 4º Desafio de Pontes de Papel.**

Botão:
**FAZER INSCRIÇÃO**

Os documentos podem abrir PDFs ou links externos.

Não criar páginas internas apenas para esses documentos.

---

# 10. RESULTADOS

Caso já existam resultados oficiais, criar uma seção:

## Resultados

Apresentar de forma muito simples:

### 🥇 1º Lugar

**Nome da equipe**

### 🥈 2º Lugar

**Nome da equipe**

### 🥉 3º Lugar

**Nome da equipe**

Se houver fotos das equipes vencedoras, utilizar pequenas imagens ao lado dos resultados.

Se o desafio ainda estiver acontecendo, essa seção pode ser ocultada ou substituída por:

**Resultados em breve.**

---

# 11. CONTATO

Criar uma seção final:

## Entre em contato

Apresentar apenas as informações realmente necessárias.

Exemplo:

**CEFET/RJ**

**E-mail:** contato@...

Adicionar, caso existam:

* Instagram
* Site institucional
* Outros canais oficiais

Não criar um formulário complexo se ele não for necessário.

No topo:

**CEFET/RJ**

Abaixo:

Início | O Desafio | Cronograma | Equipes | Galeria | Documentos | Contato

Na parte inferior:

Se houver informações oficiais de organização, adicionar discretamente.

# 13. IDENTIDADE VISUAL

O visual deve transmitir:

**Engenharia + Educação + Criatividade + Competição**

A estética deve ser institucional, mas não excessivamente formal.

Utilizar uma paleta simples.

### Cores sugeridas:

**Azul institucional**
Para títulos, botões e elementos principais.

**Branco**
Para o fundo principal.

**Cinza muito claro**
Para separar algumas seções.

**Cinza escuro**
Para textos.

Utilizar uma cor de destaque apenas quando necessário.

Não utilizar muitas cores.

---

# 14. TIPOGRAFIA

Utilizar uma fonte moderna, limpa e altamente legível.

Sugestões:

* Inter
* Montserrat
* Poppins
* Roboto

Utilizar:

**Títulos:** fonte mais forte/bold.

**Textos:** peso regular.

Não utilizar muitas fontes diferentes.

Idealmente utilizar apenas uma família tipográfica com diferentes pesos.

---

# 15. ESTILO DOS ELEMENTOS

Os elementos devem ser discretos.

Utilizar:

* Bordas levemente arredondadas
* Sombras muito suaves
* Espaçamento generoso
* Ícones simples
* Cards limpos
* Botões com boa área de clique

Evitar:

* Gradientes exagerados
* Animações excessivas
* Parallax pesado
* Textos piscando
* Muitos efeitos
* Fundos muito carregados
* Elementos 3D desnecessários
* Muitas cores
* Pop-ups desnecessários

O site deve parecer **profissional e acadêmico**, não um site de tecnologia ou uma landing page comercial.

---

# 16. FOTOGRAFIAS

As fotografias devem ter bastante importância no design.

Priorizar imagens reais do:

* Desafio
* CEFET/RJ
* Participantes
* Construção das pontes
* Pontes finalizadas
* Equipes
* Premiação

Não utilizar imagens genéricas se existirem fotografias reais do evento.

As imagens devem ser utilizadas de maneira consistente.

Evitar colocar dezenas de fotos apenas para preencher espaço.

---

# 17. RESPONSIVIDADE

O site deve funcionar perfeitamente em:

* Desktop
* Notebook
* Tablet
* Smartphone

No celular:

* Menu deve virar menu hambúrguer
* Cards devem ficar em uma coluna
* Imagens devem ocupar a largura disponível
* Textos devem continuar fáceis de ler
* Botões devem ter tamanho adequado para toque
* Não deve existir rolagem horizontal

---

# 18. EXPERIÊNCIA DE NAVEGAÇÃO

A navegação deve ser extremamente simples.

O visitante deve conseguir encontrar rapidamente:

**O que é o evento?**

**Como participar?**

**Quais são as datas?**

**Quais são as equipes?**

**Onde estão as regras?**

**Como entrar em contato?**

Não obrigar o visitante a entrar em várias páginas para descobrir essas informações.

A página inicial deve funcionar como o principal centro de informações do evento.

---

# 19. PRINCÍPIO MAIS IMPORTANTE DO PROJETO

O site deve ser **simples, mas não sem graça**.

Não tentar colocar elementos apenas para deixar o site "mais bonito".

Cada elemento deve ter uma função.

A prioridade visual deve ser:

**1. Nome do evento**

**2. Informações sobre o desafio**

**3. Cronograma**

**4. Equipes**

**5. Galeria**

**6. Documentos**

**7. Contato**

O resultado final deve parecer um **site oficial de um evento acadêmico do CEFET/RJ**, com aparência moderna e profissional, mas que possa ser facilmente mantido e atualizado.
